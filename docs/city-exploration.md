## 世界结构

大地图为可行走的三维城市，河流和三座桥连接七个区域。每个区域都有独立箱庭：地面广场、中央阶梯、上层平台、区域地标、人物、检修台、物资箱及邻区出口。

连接关系：
- 归城水口 ↔ 旧街管网 / 钟楼水道
- 旧街管网 ↔ 归城水口 / 蓄水高台 / 屋顶温室
- 蓄水高台 ↔ 旧街管网 / 无人苗圃
- 钟楼水道 ↔ 归城水口 / 屋顶温室
- 屋顶温室 ↔ 旧街管网 / 钟楼水道 / 无人苗圃 / 两户灯火
- 无人苗圃 ↔ 蓄水高台 / 屋顶温室 / 两户灯火
- 两户灯火 ↔ 屋顶温室 / 无人苗圃

每个区域还有「返回百阶城大地图」实体出口。原有 13 个修复任务分配到对应检修台。所有修复场景支持 M 或「大地图」按钮返回全域图，暂停时也可返回所在街区。

## 操作

WASD / 方向键：四方向移动，方向以镜头为基准。Shift：跑步。点击地面：自动寻路，避开房屋、水池、花台、人物与装置；台阶连接高低平台。点击远处交互图标：自动走近。F：与近处对象交互，E 兼容旧操作。M：全域图。ESC：关闭对话/任务面板/地图，然后返回大地图或事务所。

角色步行、跑步、朝向、镜头跟随、建筑遮挡淡化、行走路径、热点浮动、快门聚焦和区域快门转场均为实际运行效果。

到访、交谈、调查、收集、修复记录在当前游戏会话中保存，跨教学关和实验关保留；重启游戏后重置。物资箱只收录一次，检修台标记已修复任务。
