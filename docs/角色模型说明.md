## 游戏使用的 GLB 放哪里

你提供的模型已经位于 Godot 项目目录：

`assets\characters\adventure character 3d model.glb`

Godot 内的资源路径为：

`res://assets/characters/adventure character 3d model.glb`

保留这个位置与文件名。文件为 Tripo 导出的静态模型，大小 67,962,992 字节（约 64.8 MiB），包含 1 个网格、1 个材质、3 张内嵌图像，没有骨骼蒙皮或动画。网格有 1,025,798 个顶点、1,951,559 个三角面，进入游戏前需要减面、制作 LOD，并检查贴图与运行性能。

截至整理时，没有在项目 `.gd` 或 `.tscn` 中找到对此模型的引用；放入 assets 会让 Godot 导入资源，但不会自动让它出现在游戏里。

## 在 Godot 中使用

1. 打开 `project.godot`，等待 GLB 导入。
2. 将 GLB 拖入一个 3D 场景，检查比例、朝向、材质、骨骼与动画。
3. 建议创建继承场景，保存为 `res://scenes/characters/adventure_character.tscn`。此路径是建议位置，当前尚未创建该场景。
4. 在继承场景中添加游戏控制器、碰撞与动画配置，再由实际游戏场景引用。当前整理工作未修改游戏逻辑。
