# 组件尺寸设计（先定尺寸，再更新实例）

一个 Godot 单位按一米使用。以下为此游戏的美术与游玩设计值，不是建筑规范或从模型中测得的门洞尺寸。

| 组件 | 设计尺寸 | 实施方法 |
| --- | --- | --- |
| 主角 / 眼高 | 1.65 / 1.52 m | 保持人体基准 |
| NPC | 约 1.70 m | 整体等比缩放 |
| 房屋 | 宽 7.20 × 深约 6.10 × 高约 6.57 m | 按包围盒宽度统一缩放 XYZ |
| 店铺 | 宽 6.40 × 深约 5.07 × 高约 6.92 m | 按包围盒宽度统一缩放 XYZ |
| 门洞 / 楼层 | 门洞视觉目标 2.1–2.4 m；层高目标 2.8–3.2 m | 作为人工验收参考；现有整体网格不能只调整门洞而保持整体等比 |
| 钟楼 / 牌楼 | 总高 9.0 / 6.2 m | 按高度整体等比缩放 |
| 温室 / 工具房 | 总高 4.8 / 4.4 m | 按高度整体等比缩放 |
| 普通 / 大蓄水罐 | 总高 3.3 / 4.8 m | 等比缩放，自动更新占地阻挡 |
| 路灯 | 总高 3.4 m | 按高度等比缩放 |
| 长椅 | 宽 1.6 m；座面约 0.46 m | 整体等比缩放 |
| 花槽 | 宽 1.5 m；槽沿约 0.70 m | 保持花槽与花朵比例 |
| 树 | 树冠顶约 5.5 m | 树干与树冠作为一个组等比缩放 |
| 道路 / 桥面 | 常规道路 4.0 m；桥面约 3.7 m | 保留桥梁河道连接 |
| 台阶 / 高台 | 级高 0.15 m，踏步 0.35 m；高台总高 1.5 m | 保持十级台阶及导航坡度 |
| 栏杆 | 约 1.0–1.1 m | 保留可用的人体尺度 |
| 石板 | 0.8 × 0.55 m | 保持世界坐标材质尺寸 |

布局：街区后庭扩为 30 米宽，后缘延伸至 Z=-15；成对建筑中心间距 9.6 米，整体后移；城区北侧扩展以容纳新房屋。以真实模型包围盒自动生成保守的占地阻挡，再加入 0.33 米角色半径，避免视觉模型和导航范围不一致。牌楼保留中间通道，桥梁和台阶保持可通行。

统一参数入口：`res://scripts/world_dimensions.gd`。模型实测报告：`docs/组件实际尺寸.json`。已验证房屋、店铺宽度和三轴等比缩放；所有街区交互点可达；原探索回归检查通过。城区北侧背景房屋移至 Z=-18.5，以留出温室后的绕行通路。

对比预览：`本地制作工作区 / world-scale\scale-comparison.png`。改动前文件保存在同一目录，以 `.before` 结尾。
