# 连通（涌现 · TapTap Game Jam）

打开方式：Godot 4.7 或更高版本（项目为 4.7） → 导入 `project.godot` → F5 运行。

## 操作
- 点【放水】开始；点红色方块打开阀门（次数有限）；点虚线空位放/收水箱（放水前）。
- 【重置】重来当前关；通关后【下一关】。

## 四关教学顺序
1. 连通器：水位 = 水源高度，先下后上也能过去，但不会高过水源
2. 阀门：有限次打开，水才会流过去
3. 水箱：装满水的蓄水箱，放在哪个空位，水位就是那里的高度（高处的水能流下来再爬回同高）
4. 弹簧阀：上游积水达到数量后自己弹开 → 一次开阀引发连锁

## 核心规则（scripts/sim.gd，纯重力，没有任何抬升/损耗）
- 每个节点有高度；水位 = 水源/水箱所在高度，水能到达 高度 ≤ 水位 的所有连通节点
- 水箱放下就是新水源（不需要先有水到达）
- 弹簧阀：a 端节点连续有水 ≥ 阈值 tick 后弹开
- 关着的阀门两侧各自灌水到阀门处
